# SpaceShrink

SpaceShrink is an Android storage-optimization and file-utility app developed by Tejinder Pal Singh.

## What SpaceShrink does

- Compress photos and videos to reduce storage usage.
- Batch-process media.
- Convert common image formats, including HEIF/HEIC where supported by the Android device.
- Convert PDF pages to JPG/PNG and extract PDF text.
- Create PDFs from images and text.
- Create ZIP archives.
- Analyze storage and identify large media, screenshots and selected folders/media groups.
- Review duplicate/similar media before deletion.
- Move selected media to Android system Trash where supported.
- Maintain compression history.
- Provide a biometric-protected private vault.
- Provide a storage widget.

## Distribution

The primary zero-cost distribution method for this project is a signed APK published through GitHub Releases and linked from a GitHub Pages website.

Users should download APKs only from the official SpaceShrink release page maintained by the developer.

## Installation

1. Download the latest signed APK from the official release page.
2. Open the APK on an Android device.
3. Android may require permission to install from the source used to obtain the APK.
4. Install and launch SpaceShrink.

## Privacy

SpaceShrink is designed to perform core compression and conversion work locally on the device. The current Android manifest does not request the INTERNET permission. Media access is handled through Android media APIs and user/system consent mechanisms where applicable.
