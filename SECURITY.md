# Security Policy

## Supported versions

Security fixes are generally targeted at the latest published SpaceShrink release.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

Please do not post a suspected security vulnerability in a public GitHub issue.

Instead, contact the developer privately using the security/support contact published on the official SpaceShrink website or GitHub profile. Include:

- SpaceShrink version
- Android version
- Device model, if relevant
- Steps to reproduce
- Expected behavior
- Actual behavior
- Any proof-of-concept or logs that are safe to share

Please avoid sending private media or personal documents unless they are required for reproducing the issue.

## Disclosure

Please allow reasonable time for the issue to be investigated and, where appropriate, fixed before public disclosure.
