# Support

For help with SpaceShrink, first check the README and the release notes for your installed version.

When reporting a problem, include:

- SpaceShrink version
- Android version
- Device model
- The exact feature you selected
- What you expected to happen
- What actually happened
- The first relevant error message from Logcat, if available

Do not post personal photos, videos, documents, biometric information, passwords, signing keys, API keys, or other sensitive information in a public issue.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) rather than opening a public issue.
